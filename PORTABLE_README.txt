Nicevideodown 2.2.1 Windows 便携版

使用方法：
1. 请先完整解压 ZIP 压缩包，不要直接在压缩包内运行。
2. 双击“视频下载神器.exe”启动软件。
3. 请勿删除同目录中的 DLL、locales、resources、yt-dlp.exe、ffmpeg.exe、ffprobe.exe 或 aria2c.exe。
4. 支持 Windows 10/11 64 位；如平台规则变化导致解析失败，请先从 GitHub Releases 获取新版。
